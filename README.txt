QR QuickShare
=============

A simple QR code generator website using the two APIs from your activities:
1. SweetAlert2 for alerts and confirmation pop-ups.
2. QR Server API for generating QR code images.

HOW TO OPEN IN VS CODE
1. Extract QR_QuickShare.zip.
2. Open VS Code.
3. Click File > Open Folder.
4. Select the QR_QuickShare folder.
5. Open index.html in your browser.

RECOMMENDED
Install the "Live Server" extension in VS Code.
Right-click index.html and select "Open with Live Server".

INTERNET REQUIRED
SweetAlert2 is loaded from jsDelivr CDN.
QR codes are generated by api.qrserver.com.
The page needs internet access for both services.

FILES
index.html - website structure
style.css  - design and responsive layout
script.js  - QR API, SweetAlert2, download, copy, and history
